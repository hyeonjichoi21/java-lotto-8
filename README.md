# java-lotto-precourse (week3)

## 구현할 기능 목록

- [ ] 로또 구입 금액 입력받기 (1,000원 단위)
- [ ] 구입 수량 계산 후 로또 티켓 N장 발행 (1~45, 중복 없는 6개, 오름차순)
- [ ] 당첨 번호 입력받기(쉼표 구분 6개)
- [ ] 보너스 번호 입력받기(1개)
- [ ] 각 티켓과 당첨 번호 비교 → 일치 개수/보너스 여부 판정
- [ ] 등수 집계(1~5등) 및 총 수익 계산
- [ ] 수익률 계산 (소수점 둘째 자리 반올림)후 출력
- [ ] 예외 발생 시 IllegalArgumentException 던지고 "[ERROR]" 접두사로 메시지 출력 후 해당 입력부터 재진행

---

### ➡️ 입력
1) 구입 금액
- 검증
  - 정수인지
  - 1,000원 단위인지 (amount % 1000 == 0)
  - 1,000원 이상인지 
- 허용: 앞뒤 공백(trim)
- 예외: [ERROR] 구입 금액은 1,000원 단위의 양수여야 합니다. 

2) 당첨 번호 (예: 1,2,3,4,5,6)
- 검증
  - 쉼표 기준 6개 
  - 모두 정수 & 범위 1~45
  - 중복 없음 
- 예외: [ERROR] 당첨 번호는 1부터 45 사이의 중복되지 않은 6개여야 합니다.

3) 보너스 번호 (예: 7)
- 검증
  - 정수 & 범위 1~45
  - 당첨 번호와 중복 불가
- 예외: [ERROR] 보너스 번호는 1부터 45 사이이며 당첨 번호와 중복될 수 없습니다.
